# IRIS
# IRIS Data Classification with SVM

## Overview
This project focuses on classifying the Iris dataset using a Support Vector Machine (SVM). The dataset consists of different species of Iris flowers and their respective sepal and petal measurements. The model is trained and evaluated using Scikit-learn's SVC (Support Vector Classification).

## Dataset
The dataset used in this project is read from `ml2.csv`, which contains the following features:
- `SepalLengthCm`
- `SepalWidthCm`
- `PetalLengthCm`
- `PetalWidthCm`
- `Species` (Target Variable)
